Plataforma Inteligente para Análise de Viabilidade de Energia Solar e Eólica
Visão Geral
Este projeto consiste no desenvolvimento de uma plataforma web que avalia automaticamente o potencial de geração de energia solar e eólica para qualquer localização geográfica. A solução utiliza dados abertos de satélites do programa Copernicus para processar informações climáticas e ambientais, gerando uma classificação de viabilidade (alta, média ou baixa) para ambas as fontes de energia renovável.

Problema Resolvido
Pessoas físicas e jurídicas enfrentam dificuldades para acessar informações técnicas confiáveis sobre o potencial energético de suas localizações. A falta de ferramentas acessíveis e automatizadas para avaliação de viabilidade de sistemas solares e eólicos representa uma barreira significativa para a adoção de energias limpas. Este projeto elimina essa barreira ao oferecer uma solução digital gratuita e de fácil utilização.

Funcionalidades
Entrada de endereço ou coordenadas geográficas pelo usuário

Coleta automatizada de dados climáticos via API Copernicus

Processamento de dados de radiação solar e velocidade do vento

Classificação automática de viabilidade energética em três níveis

Dashboard interativo para visualização dos resultados

Tecnologias Utilizadas
Frontend: HTML, CSS, JavaScript

Backend: Java

Banco de Dados: MySQL

API: Copernicus Satellite Data
Resultados Entregues
Ao final do projeto, será entregue uma plataforma funcional acessível via navegador, capaz de processar dados climáticos em tempo real e apresentar um dashboard com indicadores claros de viabilidade energética para energias solar e eólica.
